  - 图片加载骨架每个节点都播放整块尺寸的微光：打开大画布时上百个排队节点同时动画，150 个节点平移 49fps、合成层 167 个。现在只有占用下载并发位（最多 4 个）的图片播放微光，排队中的骨架静止；同条件 60fps、合成层 21 个。

## 生成状态重设计：画布节点与首页创作，等待中断不再判为生成失败
