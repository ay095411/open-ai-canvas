# 短剧 Agent 页面模块整体优化方案

经过对当前前端路由（`/projects`、`/projects/new`、`/projects/:projectId`）、画布内 Agent 集成模块（`canvas-short-drama-entry`、`canvas-cloud-agent-panel` 等）以及底层 API 链路的全面深入分析，结合当前存在的交互割裂、名实不一致与操作冗余痛点，提出以下整体优化方案。

---

## 一、现状核心痛点与诊断分析

### 1. 概念与心智割裂（“短剧 Agent”有名无实）
- **侧栏入口断层**：侧栏导航名称为「短剧 Agent」，用户期望的是由 AI Agent 深度协同创作的短剧中心；但点击跳转到 `/projects` 后，呈现的却是一个传统的“上传小说文件列表”，没有任何 Agent 的对话、思考或辅助生成入口；
- **首页引导混乱**：创作首页大卡片写着「短剧 Agent 创作助手」，点击后却是新建一张自由画布（`/canvas?agent=1`），导致“短剧”与“画布”的定位边界模糊；
- **创作门槛过高**：当前新建短剧强制要求用户上传现成的长篇 TXT/MD 小说文件；如果创作者只有一个灵感点子或故事大纲，在系统内无法通过短剧 Agent 启发式生成或大纲扩写。

### 2. 新建流程（`/projects/create.tsx`）交互臃肿
- **全量表单一次性平铺**：进入新建页后，风格、参考图方案、模型选择、审阅模式、时长规则、算力预估等数十个底层参数一次性全盘推给用户，认知负荷大；
- **缺乏视觉反馈与即时预览**：用户在选择 9:16 / 16:9 画幅或视觉风格时，界面上没有动态联动的画幅比例与定妆样张预览。

### 3. 短剧制作工作台（`/projects/:id`）缺乏 Agent 协同闭环
- **缺少常驻 Agent 辅助**：在制作台（分集、故事板、台词本）中，镜头提示词或对白不满意时，用户只能人工长篇手动编辑，无法随时呼叫短剧 Agent 协助（例如：“Agent，帮我把这一段的冲突节奏加快”、“优化反派的对白语气”、“重写第3镜的运镜提示词”）；
- **与画布生态脱节**：短剧项目生成的剧情段和角色虽然存在数据库中，但缺乏一键“在无限画布中自由推演/排布”的双向联动。

---

## 二、整体优化方案设计

### 核心定位：将短剧模块升级为「短剧 Agent 创映工坊 (Drama Agent Studio)」
将“机械式文件处理流水线”转型为**人机协同的智能短剧孵化中心**，建立统一创作漏斗：
$$\text{【1. 创意大纲】} \longrightarrow \text{【2. 角色定妆】} \longrightarrow \text{【3. 分镜编导】} \longrightarrow \text{【4. 剧情段成片】}$$

---

### 模块一：短剧项目中心 (`/projects`) 页面重塑
1. **灵感共创双轨入口（Hero 区）**：
   - **轨道 A（AI Agent 共创）**：顶部常驻「向短剧 Agent 说出你的想法」快速发起栏，输入一句话梗概（例如“都市逆袭：落魄总裁重返商界巅峰”），点击直接由短剧 Agent 生成分集大纲；
   - **轨道 B（小说文件改编）**：保留成熟的拖拽/上传 TXT/MD 小说或粘贴正文入口，平滑兼容专业网文批量拆改。
2. **卡片视觉与信息重构**：
   - 卡片封面采用项目统一的 4:3 复合预览，未生成封面时使用精致的题材占位 tile；
   - 突出关键生产指标：分集进度环（如 `3/10 集`）、集数状态胶囊（制作中/需确认/已完成）、角色头像堆叠与修改时间；
   - 卡片悬停操作项更合理：`[ 继续制作 ]`、`[ 演职员 ]`、`[ 在画布中推演 ]`、`[ 更多/删除 ]`。

---

### 模块二：新建短剧流程 (`/projects/new`) 向导化与即时预演
将原来繁重的“全量配置长表单”改造为**轻量 3 步向导 (Wizard) + 实时右侧联动预演卡**：
- **Step 1：故事源与画幅节奏**
  - 选择输入源：上传小说 / 粘贴正文 / 或由短剧 Agent 构思大纲；
  - 画幅比例胶囊：`9:16 (短剧)`、`16:9 (横屏)`、`1:1 (方屏)`；
  - 单集节奏选择：预设常用短剧时长（60秒极速 / 90秒标准 / 120秒详尽）。
- **Step 2：艺术风格与角色定妆方案**
  - 精选视觉风格卡片点选（赛博科幻、古风仙侠、都市悬疑、写实胶片等），带封面图与光效；
  - 角色一致性方案选择（首选生成三视图 / 自动绑定主角参考图）。
- **Step 3：生产模式与启动**
  - 简明易懂的三种模式胶囊：
    - 🌟 **先看样片（推荐）**：做完第 1 集合成片供用户确认角色声线，满意后批量推进；
    - 🔍 **分段把控**：每集生成视频前停下确认提示词；
    - ⚡ **全自动狂飙**：不打断一键跑到成片。
  - 右侧预估面板实时计算：预计集数、镜头数、算力消耗与预计时长，点击清晰启动。

---

### 模块三：制作工作台 (`/projects/:id`) 沉浸式三栏工作台
1. **左侧：分集导轨 (Episode Rail)**
   - 更加紧凑的竖向分集清单，清晰标识各集状态（大纲就绪、分镜待审、视频生成中、成片已出）；
   - 支持键盘快捷键 `[` / `]` 极速切集，分集拖拽排序与批量操作。
2. **中间舞台：多视角视图自由切换**
   - **故事板视图 (Storyboard)**：分剧情段流水卡片，左侧镜头关键帧 + 中间台词与角色 + 右侧运镜与重试按钮；
   - **剧本对白视图 (Script)**：沉浸式剧本文本排版，台词、场景、动作描述层级分明；
   - **成片视听视图 (Final View)**：集成全屏/画中画播放器，支持视频合集无缝串联与单段重新微调。
3. **右侧：常驻「短剧 Agent 协作面板」**
   - 用户无需离开当前页面，右侧随时唤起短剧专项 Agent；
   - 内置快捷指令胶囊：`[ 强化本集冲突 ]`、`[ 润色台词语气 ]`、`[ 重写运镜提示词 ]`、`[ 重新换脸 ]`；
   - 用户可对话打字向 Agent 提要求，Agent 直接通过 API 局部更新当前集的剧情段与提示词，避免繁琐的手动编辑。
4. **与自由画布无缝联动**：
   - 顶栏增加 `[ 在画布中推演 ]` 按钮，点击将当前集的一整套分镜节点镜像投射到一张独立的短剧画布中，用户可在画布上进行框选替换、局部重绘与自由排布，改动自动回写短剧项目。

---

### 模块四：样式与视觉规范对齐
- **暗黑主题与质感统合**：全面复用已有的 `--user-*`、`--wb-*` 以及设计系统 Token，告别突兀的亮白底和粗硬边框；
- **控制尺寸与间距统一**：按钮高度（34px/40px）、输入框、标签徽章与图标对齐全站统一的垂直居中规范；
- **微交互与状态动效**：状态流转带有温和的呼吸与骨架屏，错误状态提供可恢复的明确指引。

---

## 三、分阶段实施规划

1. **第一阶段：短剧列表中心与入口梳理**
   - 改造 `/projects` 列表页：增加顶部灵感快速孵化卡，重构作品列表卡片的封面排版、进度环与操作项；
   - 保持与侧栏「短剧 Agent」和首页大卡的无缝衔接。
2. **第二阶段：新建向导 3 步法重构 (`/projects/new`)**
   - 将现有平铺表单重构为分步式向导（故事规格 → 视觉角色 → 生产预算），增加右侧实时联动预演卡。
3. **第三阶段：制作台 Agent 协作侧栏与操作优化 (`/projects/:id`)**
   - 在工作台集成右侧专属「短剧 Agent」辅助面板，支持针对单集/单段镜头快速发出修改指令；
   - 打通工作台与画布之间的一键推演通道。
4. **第四阶段：构建验证、测试覆盖与浏览器端核验**
   - 运行类型检查、单元测试与打包构建，实机通过浏览器测试各链路流转体验。
